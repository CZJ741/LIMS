# LIMS 实验室信息管理系统 (Python + MySQL/SQLite + Web)

本工程基于真实环境检测与分析实验中心业务规格（还原原系统 `http://82.157.0.164` 结构与 UI 交互）构建，具备完整的**委托单受理 -> 样品流转 -> 实验室上机检测与数据录入 -> CMA/CNAS 报告签发**闭环。

---

## 一、系统架构与技术选型

1. **后端服务 (Python)**:
   - **框架**：FastAPI (异步高性能、全自动 OpenAPI/Swagger 文档)
   - **ORM**：SQLAlchemy 2.0
   - **数据库**：MySQL（默认优先连接本机 MySQL 3306，未配置或未启动时平滑 fallback 持久化 SQLite，保证即开即用）
   - **驱动与加解密**：PyMySQL、Pydantic v2、Cryptography

2. **前端界面**:
   - **技术栈**：Vue 3 + Element Plus 极简响应式轻量架构（无需冗长 node_modules 构建，直接开箱即用）
   - **UI 风格**：100% 还原原系统工业蓝（`#001529` / `#1890ff`）管理控制台、多级导航树与可折叠侧边栏、流转状态徽章与多 Tab 标签页。
   - **业务树**：完整抓取并收录目标系统的 30 个根业务模块与近 200 个子功能菜单（已保存于 `menu_nav.json` 并内置 API 路由）。

## 二、快速启动运行

### 方式 1：双击批处理脚本（推荐）
在项目根目录直接双击运行：
```bash
start_lims.bat
```

### 方式 2：命令行手动启动
```bash
cd lims_backend
python run.py
```

启动后控制台会输出：
- 后端服务地址：`http://127.0.0.1:8000`
- **Swagger 接口交互文档**：[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- **统一登录页面**：[http://127.0.0.1:8000/web/login.html](http://127.0.0.1:8000/web/login.html)
- **管理员工作台主页**：[http://127.0.0.1:8000/web/index.html](http://127.0.0.1:8000/web/index.html)

## 四、核心业务流演示操作

1. **统一登录**：
   - 访问 `/web/login.html`，支持一键填入 `admin` / `123456`，校验通过后进入主控台。
2. **委托单管理**：
   - 查看现有委托项目；点击【新建委托单】，输入委托企业与检测项目，系统自动生成 `WT-` 编号。
3. **样品流转**：
   - 进入【样品登记与台账】，为样品自动分发唯一条码编号（`YP-`），绑定对应委托协议并指定冷藏保存条件。
4. **实验室检测与数据录入**：
   - 进入【实验室检测管理】，查看 COD、氨氮、总磷等指标任务，点击【录入/修改数据】，录入实测仪器读数并完成双人复核。
5. **检测报告中心**：
   - 查看编制中报告，点击【批准签发】完成闭环。

## 五、MySQL 数据库配置（可选）

如需使用已安装的 MySQL 数据库，确保 MySQL 服务启动并在环境变量中指定即可（默认连接 `127.0.0.1:3306` 用户名 `root` 密码 `123456`），亦可直接将 `lims_backend/schema.sql` 导入 MySQL。
