# LIMS 岗位操作规程：报告编制员 (REPORT_WRITER)

## 1. 角色职责与权限范围
- **对应职位代码**：`REPORT_WRITER`
- **主要职责**：负责接收已完成实验复审的数据流转，根据检测项目指标选择标准化模板，编写技术评价结论，完善图谱附录，并提交报告审核员进行三级签审。
- **核心操作权限**：`report:edit`, `report:query`, `file:upload`, `file:download`

## 2. 核心业务操作流程
```
[检测完成/数据归档] ──> [认领编制任务] ──> [选择受控模板] ──> [校核检测数值] ──> [填报评价结论] ──> [提交技术审核]
```

### 步骤一：查看待编制任务
1. 登录系统后，在个人工作台【我的待办】中筛选流程阶段为 `REPORT` 的任务；
2. 点击进入【报告管理】->【报告编制】页面，确认样品编号、检测项目以及对应的标准方法。

### 步骤二：在线编制与模板预览
1. 点击操作栏中的【编制报告】，进入报告编辑界面；
2. 系统已自动关联检测复审数据（如未检出、检出限、测量不确定度等）；
3. 录入综合判定结论（如：“经检验，所测指标符合《GB 3838-2002 地表水环境质量标准》Ⅲ类标准限值”）；
4. 点击【实时预览】生成临时 PDF 视图，核对排版对齐与表格分页。

### 步骤三：提交审核与驳回处理
1. 核验无误后，点击【提交审核】，流程流转至报告审核员节点；
2. 若收到【审核驳回】通知，在编制列表可查看审核员批注的具体意见（不少于10字），根据修改建议修正后重新提交。

## 3. 常见问题 FAQ
- **Q1: 为什么提示“检测数据未完全归档，无法发起编制”？**
  - **答**：该委托单项下尚有部分样品检测指标处于复审阶段，需等待数据复审人全部通过后方可流转。
- **Q2: 发现原始检测数据有明显录入偏差，编制员能否直接在报告中修改数值？**
  - **答**：严禁直接篡改。依据 ISO 17025 规范，编制员应联系实验数据复审员执行【流程回退】，退回分析员重新核实。
